# 攻坚路线（notes/strategy.md）

目标：证明 Thomson 问题 N = 11 的全局最小能量 `E₁(11) = 40.596450508…`，最小化构型在相差
`O(3)` 与重排下唯一（数值上为 C2v 的「边收缩二十面体」，见 `PROGRESS.md` 1.3 与
`README.md` 2）。本文件是路线图，不是已完成的证明；里程碑 M0/M1 已按此路线钉进挑战文件。

## 1. 方法来源

- **KLT N = 8 论文**（`references/klt-n8-paper.pdf`，arXiv:2609.22077，本次已通读）：Cohn–Woo
  三点半定（SDP）框架 + Hermite 插值多项式次估 + 精确有理/代数证书 + 等式情形恢复。其 N = 8
  定理的形态是本仓库最终命题形态的模板（见第 5 节）。
- **N = 7 已验证工程**（`references/thomson-n7-lean/`）：slab 分裂 + 管状邻域 + 刚性论证 +
  二阶局部最优性定理的完整 Lean 实现蓝本；其 `check.sh`/`compare_statements.py`/负控制等验收
  机制已搬入本仓库 `formal/lean/scripts/`。
- **分层验证框架**：任务书引用「Vals AI 四层方法」表述本项目的验证分层（数值复现 → 严格数值 →
  证书化 SDP → Lean 形式化）。本仓库未拿到 Vals AI 的原始文献，故本文按任务书的分层框架表述，
  技术锚点一律落在 KLT 论文与 N = 7 仓库这两份已读材料上，不虚构其内容。

四层分层在 KLT/N=7 中的对应物：

| 层 | 内容 | KLT / N=7 中的实例 |
| --- | --- | --- |
| L1 数值复现 | 多起点优化找候选、定结构 | 本仓库 `numerics/`（已完成） |
| L2 严格数值 | 区间算术包住能量/梯度/谱 | KLT 第 6 节（2⁻²⁵⁶ dyadic 区间） |
| L3 证书化 SDP | 精确有理数据的三点界，Lean kernel 内 `decide` | KLT 第 4–6 节；N=7 的 typed 三点证书 |
| L4 Lean 形式化 | 语句比对、公理检查、负控制、（可选）第二内核 | N=7 的 `check.sh` + Comparator + nanoda |

## 2. 核心技术：三点 SDP 上界（KLT 第 2–4 节的移植）

1. **多项式次估**：把库仑势 φ(t) = (2−2t)^{−1/2}（t 为内积）从下方用 Hermite 插值多项式
   H(t) 逼近，插值节点取候选构型实际出现的内积值集合。余项符号由 φ 的高阶完全单调性控制
   （KLT 引理 4.1 的 (13) 阶导数论证）。于是 `Ê(Y) ≥ E_H(Y) := Σ_{i<j} H(yᵢ·yⱼ)`。
2. **三点恒等式**：构造标量平方和项 + 矩阵值核，使得对任意构型 Y，
   `12 (E_H(Y) − E_H(候选)) ≥ Σ 三角形 SOS 项 + 矩阵矩项`，后者由构型的 PSD 矩条件
   （对所有有序三元组求和的矩矩阵 Mₖ ⪰ 0）保证非负（Cohn–Woo 框架）。
3. **精确证书**：恒等式是多项式系数方程组；用有理向量起笔、精确修正到满足（KLT 的 99 个独立
   系数条件做法）；PSD 性在小邻域内用区间算术验证，然后转成 Lean kernel 可 `decide` 的
   整数/有理数据。
4. **N = 11 的规模**：候选构型有 **20 个不同内积值**（N = 8 只有 4 个类型），插值条件数与
   恒等式的单项式系数方程数显著增大；首次实施时先用**较少节点**（如只取 H 的低次逼近）拿到
   M1 = 38.75 这一较松的有理界，把全节点精确界留给最终定理。

## 3. slab 分裂（N = 7 仓库的做法移植）

单一全局 SDP 界可能无法一步达到真值。N = 7 工程的对策（其 README 第 "What is established"
节的公开摘要）：按**最小内积**（最「接近对径」的点对）分情形：

- 无近对径点（最小内积 ≥ 某阈值）：一个全局三点 SDP 界即可；
- 其余区域切成若干 **slab**（最小内积的区间）+ 一个含候选的 **cap**：每个 slab 配自己的
  typed 三点证书（阈值、节点、区间参数都随 slab 改变）。

N = 11 的分裂变量仍首选最小内积（候选的最小内积是 −0.999022793——注意它**非常接近 −1**，
即候选含一对近对径点，这决定了 cap 的形状要在对径方向拉长）；备选分裂变量：次小内积、或
最大点间距。分裂参数（阈值表）由 L2 严格数值预研确定。

## 4. 管状邻域 + 刚性论证（收尾）

含候选的 cap 内，仿 N = 7：证明能量在候选的一个**管状邻域**（对构型空间的 Hausdorff 型度量）
内被二阶条件控制（Hessian 在切空间上一致正定，L2 区间验证），邻域内最小点唯一；再证任何落在
邻域外的构型能量 > 40.5964505…（由该 slab 的证书），从而全局最优 + 唯一性。

刚性论证的 N = 11 难点：候选只有 C2v 对称，没有 N = 7 五角双锥那种大对称群可借力；等式情形
恢复将走 KLT 的 **Coulomb 案路线**（第 5 步）：由次估的严格等式集推出所有两两内积都属于候选
的 20 值集合 → 取 3 点生成 R³ 基 → 其余 8 点由其与基的内积三元组唯一决定 → 有限 Gram 枚举
（机器枚举 + Lean 可查表）穷尽所有可能，逐一排除或归并到候选。20 值集合使枚举规模远大于
N = 8（那里是 4 值），需要预筛（距离三角形不等式、Gram PSD 性）。

## 5. 最终命题的目标形态（不进挑战文件，方向性记录）

仿 KLT 对 N = 8 方反棱柱高度 `a_s` 的处理（命题 3.1：平稳性方程 F(s,a) = 0 在 (0,1) 有唯一
解，该解隐式刻画最优构型；定理 1.1 直接引用 `X(a_s)`）：N = 11 的最终 Lean 命题预期形如

> **候选写法 A（推荐，隐式刻画）**：定义 `w : R3 → Fin 11 → ℝ` 型的参数化构型族
> `candFamily(p)`（C2v 轨道 1+2+2+2+4 的显式角参数化，约 12 个自由参数），以及平稳性方程组
> `stat(p) = 0`（切向梯度为零的 22−3 个独立方程的有理函数形式）。定理：
> (i) `stat` 在某紧集内有唯一解 `p*`；(ii) `∀ x ∈ SphereConfig 11,
> coulombEnergy (candFamily p*) ≤ coulombEnergy x`；(iii) 等号 ⇒ x 与 `candFamily p*`
> 相差正交变换与重排。
>
> **候选写法 B（更省力、更弱）**：不定义族，直接以「能量 ≤ 40.6」刻画：
> `∃ y ∈ SphereConfig 11, (∀ x ∈ SphereConfig 11, coulombEnergy y ≤ coulombEnergy x) ∧
> coulombEnergy y < 40.6`——先证存在性 + 定量上界，唯一性另立定理。

写法 A 的 (i) 是新的重活（唯一性需区间牛顿或单调性论证），但与 KLT 的结构完全平行；写法 B
可作为 M1 与最终定理之间的过渡里程碑（M2）。**定稿前先跑通 SDP 上界，看 38.75 → 40.596…
的界阶梯再定。**

## 6. N = 11 的特有机会与风险

**机会**

- 定义层零成本：`R3/SphereConfig/coulombEnergy/cyl` 与 N = 7 已验证工程逐字相同，
  语句比对、负控制等验收机制整套搬运，Lean 侧地基是别人付过钱的。
- 候选结构完全摸清（本仓库 L1 已完成）：C2v、轨道 1+2+2+2+4、20 个内积值的多重集、
  「缩棱二十面体」的构造性来源（这些直接喂给 L2/L3 的参数选择）。
- 候选的最小内积 −0.999022793 接近 −1：含一对近对径点，slab 分裂的「无对径点」分支可以放
  很宽的阈值（候选在最深 slab 里），前几个 slab 的证书条件相对宽松。
- M0（27.5）极弱：连经典两点界（Yudin 型）都能过，是 Lean 侧的第一个可证目标，用来把
  Solution.lean 的基础设施（能量展开引理、球面约束处理）搭起来。

**风险**

- **无单参数闭式族**：N = 7/8/9 分别有零/一/一个参数的闭式族，N = 11 只有 12 参数的显式族 +
  平稳性方程，候选的 Lean 侧定义和「能量闭式」都重得多（55 对距离没有一个能写成少量
  sin/cos 的组合）。
- **20 个内积值**：Hermite 插值多项式次数高（节点 20 + 导数匹配 → 次数 ~40+？KLT 是 13 个
  条件、次数 12），系数证书规模暴涨；可能必须放弃「全节点精确匹配」改用「低数次估 + slab」
  的 N = 7 式组合（这本身就是 N = 7 选择 slab 路线的原因）。
- **地形险恶**（本仓库实测）：一阶优化 60/60 落入同一极小；诱饵极小（去顶二十面体，40.615117337）
  仅比全局高 0.019，且文献综述常把它误当全局；任何「数值直觉」都必须过 L2 区间层才能引用。
- **上游数据错误已发生一次**：任务书参考能量录错（勘误记录见 `PROGRESS.md` 3）。后续所有
  外部数值（含本仓库自己的 L1 输出）在进入定理陈述前都要三源核对或区间证明。
- Lean 工程量：N = 7 的解是 17,895 行、十个 agent × 15 小时；N = 11 的等式情形枚举规模更大，
  预算只多不少。M1（38.75）与最终定理之间应设 1–2 个中间里程碑（如写法 B 的 M2）以便分次运行。
